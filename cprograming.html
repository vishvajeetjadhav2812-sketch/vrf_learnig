C, down to the metal.

C doesn't hide anything from you — memory, pointers, the exact size of every type, it's all right there. That's what makes it demanding to learn and invaluable once you have: understanding C means understanding how computers actually work underneath every higher-level language built on top of it.

Level Beginner → Intermediate Reading time ~40 min Standard C11 / C17 examples

01 What is C?

A procedural, statically-typed systems language that has quietly powered nearly every operating system, compiler, and embedded device since the 1970s.

C was developed by Dennis Ritchie at Bell Labs between 1969 and 1973, created alongside the early versions of Unix — in fact, Unix was rewritten in C shortly after, which is part of why the language spread so widely. Its significance is hard to overstate: the Linux kernel, Python's own interpreter (CPython), most databases, and most embedded firmware are written in C or a language directly descended from it.

Core features

Procedural

Code is organized around functions that execute in sequence, operating on data you pass explicitly.

Fast

Compiles directly to native machine code with minimal runtime overhead — no garbage collector, no interpreter.

Low-Level Memory Access

Pointers let you read and write memory addresses directly, giving fine control most languages don't expose.

Portable

A C compiler exists for nearly every processor architecture, so the same source runs almost anywhere with minor changes.

Small Core Language

Roughly 32 keywords. Everything beyond the essentials comes from libraries, not language syntax.

Manual Memory Management

You allocate and free memory yourself with malloc/free — powerful, but the responsibility is entirely yours.

02 The Compilation Process

Unlike Python, a C program can't run until it's transformed through four distinct stages into a native executable.

1

Preprocessing

Expands #include and #define directives, strips comments. Output: expanded source (.i)

2

Compilation

Translates the preprocessed code into assembly language for the target CPU. Output: .s

3

Assembly

The assembler converts assembly code into machine code object files. Output: .o / .obj

4

Linking

Combines object files and libraries (like stdio) into a single executable. Output: .exe / a.out

terminal
# all four stages, triggered by one command:
gcc program.c -o program
 
# run just one stage at a time, to see the output of each:
gcc -E program.c -o program.i     # preprocessing only
gcc -S program.c -o program.s     # compilation only
gcc -c program.c -o program.o     # assembly only
gcc program.o -o program          # linking only

03 C vs C++ vs Java

Three languages that share syntax roots but make very different tradeoffs.

CC++Java
ParadigmProceduralProcedural + OOPPurely OOP
Memory managementManual (malloc/free)Manual or RAII/smart pointersAutomatic (garbage collected)

C++ is often described as "C with classes" — it's a near-superset of C, which is why most C code compiles as valid C++ with little modification.

04 Basic Structure of a C Program

Every C program shares the same skeleton: headers, then a mandatory entry point.

structure.c
#include <stdio.h>          /* brings in printf, scanf, etc. */
 
int main(void) {              /* execution always starts here */
    printf("Program starts here.\n");
    return 0;                    /* 0 tells the OS the program succeeded */
}
  • #include pulls in a header file's declarations before compilation.
  • main() must return an int — 0 conventionally means success, nonzero means an error occurred.
  • Every statement ends in a semicolon; blocks are wrapped in curly braces.

06 Variables, Constants & Scope

Where a variable is declared determines where it can be used — and C gives you two distinct ways to define a constant.

scope_and_const.c
#include <stdio.h>
 
int globalCount = 0;                  /* global -- visible to every function below it */
#define MAX_USERS 100              /* preprocessor constant -- replaced before compiling */
 
void incrementCount(void) {
    const int STEP = 1;             /* const -- a real, typed variable that can't change */
    globalCount += STEP;
}
 
int main(void) {
    int localCount = 5;             /* local -- only exists inside main() */
    incrementCount();
    printf("Global: %d, Local: %d, Max: %d\n", globalCount, localCount, MAX_USERS);
    return 0;
}
#define is a text substitution done by the preprocessor before compilation even starts. const creates a genuine, type-checked variable the compiler enforces — prefer const in modern code.

07 Input / Output

printf and scanf rely on format specifiers to know exactly how to interpret each value.

io.c
#include <stdio.h>
 
int main(void) {
    int age;
    float gpa;
    char grade;
 
    printf("Enter your age: ");
    scanf("%d", &age);          /* & -- passes the address, so scanf can write into it */
 
    printf("Enter your GPA: ");
    scanf("%f", &gpa);
 
    grade = (gpa >= 3.5) ? 'A' : 'B';
    printf("Age: %d, GPA: %.2f, Grade: %c\n", age, gpa, grade);
    return 0;
}

08 Operators

C's operator set is where a lot of "clever" low-level code comes from — especially the bitwise family.

Arithmetic

+ - * / % — integer division truncates: 7 / 2 is 3, not 3.5.

Relational

== != > < >= <= — return 1 (true) or 0 (false), since C has no true bool type in older standards.

Logical

&& || ! — combine conditions; short-circuit like most languages.

Bitwise

& | ^ ~ << >> — operate directly on the binary bits of an integer.

Assignment

= += -= *= /= — compound forms combine a calculation with the assignment.

Ternary

cond ? a : b — a compact inline if-else that evaluates to a value.

operators.c
int flags = 0b1010;
int masked = flags & 0b0010;      /* bitwise AND -- checks if bit is set */
int shifted = flags << 1;        /* left shift -- multiplies by 2 */
 
int max = (10 > 20) ? 10 : 20;   /* ternary -- max becomes 20 */

09 Control Statements

Branching, looping, and C's often-discouraged fifth jump statement: goto.

control_flow.c
int score = 76;
 
if (score >= 90) {
    printf("Grade: A\n");
} else if (score >= 75) {
    printf("Grade: B\n");
} else {
    printf("Grade: C or below\n");
}
 
switch (score / 10) {
    case 10:
    case 9:
        printf("Excellent\n");
        break;                 /* without break, execution "falls through" to the next case */
    default:
        printf("Keep practicing\n");
}
 
for (int i = 0; i < 5; i++) {
    if (i == 3) continue;   /* skip this iteration */
    if (i == 4) break;      /* exit the loop entirely */
    printf("i = %d\n", i);
}
goto jumps directly to a labeled line and is almost always avoidable with loops and functions. It survives mainly for breaking out of deeply nested loops or centralized cleanup code in older C codebases.

10 Two Complete Programs

The smallest possible C program, and a factorial finder that uses a loop to build up a result.

Hello, World

hello_world.c
#include <stdio.h>
 
int main(void) {
    printf("Hello, World!\n");
    return 0;
}

Factorial Finder

factorial.c
#include <stdio.h>
 
int main(void) {
    int n;
    unsigned long result = 1;
 
    printf("Enter a positive integer: ");
    scanf("%d", &n);
 
    if (n < 0) {
        printf("Factorial is undefined for negative numbers.\n");
        return 1;
    }
 
    for (int i = 1; i <= n; i++) {
        result *= i;
    }
 
    printf("%d! = %lu\n", n, result);
    return 0;
}

11 Functions & Call Types

A function has three parts in C: a declaration (the promise), a definition (the body), and a call (the use).

The function receives a copy of the argument. Changes made inside the function never affect the original variable.

call_by_value.c
void tryToDouble(int x) {
    x = x * 2;              /* only changes the local copy */
}
 
int main(void) {
    int num = 5;
    tryToDouble(num);
    printf("%d\n", num);    /* still 5 -- the original was untouched */
    return 0;
}

The function receives a pointer to the original variable's memory address, so changes inside the function are visible outside it.

call_by_reference.c
void doubleIt(int *x) {
    *x = *x * 2;          /* dereference -- modifies the real value */
}
 
int main(void) {
    int num = 5;
    doubleIt(&num);         /* & passes num's address */
    printf("%d\n", num);    /* 10 -- the original was modified */
    return 0;
}

12 Recursion

A function that calls itself, working toward a base case that stops the chain.

fibonacci.c
#include <stdio.h>
 
int fibonacci(int n) {
    if (n <= 1) {          /* base case -- stops the recursion */
        return n;
    }
    return fibonacci(n - 1) + fibonacci(n - 2);   /* recursive case */
}
 
int main(void) {
    for (int i = 0; i < 8; i++) {
        printf("%d ", fibonacci(i));   /* 0 1 1 2 3 5 8 13 */
    }
    return 0;
}
Every recursive function needs a base case, or it will keep calling itself until it exhausts the call stack — a "stack overflow" in the literal, original sense of the term.

14 Arrays

A fixed-size, contiguous block of memory holding elements of the same type — the building block for almost every other data structure in C.

arrays.c
int scores[5] = {88, 92, 79, 65, 99};   /* 1D array -- 5 contiguous ints */
printf("%d\n", scores[2]);                    /* 79 -- indexing starts at 0 */
 
int grid[2][3] = {                        /* 2D array -- rows x columns */
    {1, 2, 3},
    {4, 5, 6}
};
printf("%d\n", grid[1][2]);                     /* 6 -- row 1, column 2 */
In memory, scores is one unbroken block: scores[0] and scores[1] sit at adjacent addresses. This is exactly why array indexing is fast — the compiler just computes base_address + (index * element_size).

15 Strings

C has no dedicated string type — a string is just a char array ending in a null terminator, '\0'.

strings.c
#include <stdio.h>
#include <string.h>
 
int main(void) {
    char first[20] = "Hello";      /* 'H','e','l','l','o','\0' under the hood */
    char second[] = ", World!";
 
    printf("Length: %zu\n", strlen(first));   /* 5 -- doesn't count the '\0' */
 
    strcat(first, second);                /* appends second onto first */
    printf("%s\n", first);              /* "Hello, World!" */
 
    char copy[30];
    strcpy(copy, first);                  /* copies first into copy */
 
    if (strcmp(first, copy) == 0) {      /* 0 means the strings are identical */
        printf("Strings match.\n");
    }
    return 0;
}

16 Pointers & Dynamic Memory

A pointer holds a memory address rather than a value directly. This is the single most powerful — and most dangerous — feature in C.

pointer_basics.c
int num = 42;
int *ptr = &num;              /* ptr stores num's memory address */
 
printf("Value: %d\n", num);     /* 42 */
printf("Address: %p\n", (void*)&num);
printf("Via pointer: %d\n", *ptr);  /* *ptr "dereferences" -- follows the address to the value */
 
int arr[] = {10, 20, 30};
int *p = arr;                /* array name decays into a pointer to its first element */
printf("%d\n", *(p + 1));       /* pointer arithmetic -- 20, same as arr[1] */

Dynamic memory allocation

dynamic_memory.c
#include <stdlib.h>
 
int *nums = (int*) malloc(5 * sizeof(int));   /* allocate room for 5 ints, uninitialized */
if (nums == NULL) {                              /* always check -- allocation can fail */
    printf("Allocation failed.\n");
    return 1;
}
 
int *zeroed = (int*) calloc(5, sizeof(int));   /* like malloc, but zero-initialized */
 
nums = (int*) realloc(nums, 10 * sizeof(int));   /* resize to hold 10 ints */
 
free(nums);       /* release memory back to the system -- mandatory */
free(zeroed);
nums = NULL;     /* prevents nums from becoming a dangling pointer */
Dangling pointer

Points to memory that has already been freed. Using it afterward is undefined behavior — set pointers to NULL right after freeing them.

Null pointer

Explicitly points to nothing (NULL). Dereferencing one crashes the program — always the safe value to check against.

17 Structures

A struct groups different types together under one name — C's answer to a simple object.

structs.c
struct Point {
    int x;
    int y;
};
 
struct Rectangle {         /* nested structure -- a struct containing another struct */
    struct Point topLeft;
    int width;
    int height;
};
 
int main(void) {
    struct Point p1 = {10, 20};       /* initialization */
    printf("(%d, %d)\n", p1.x, p1.y);
 
    struct Rectangle r = {{0, 0}, 100, 50};
    printf("width: %d\n", r.width);
 
    struct Point points[3] = {         /* array of structures */
        {1, 1}, {2, 2}, {3, 3}
    };
    printf("%d\n", points[1].y);        /* 2 */
    return 0;
}

18 Unions

A union looks like a struct but stores all its members in the same block of memory — only one member holds a valid value at a time.

unions.c
union Data {
    int i;
    float f;
    char str[20];
};
 
int main(void) {
    union Data data;
    data.i = 10;
    printf("%d\n", data.i);     /* 10 */
 
    data.f = 3.14;            /* overwrites data.i -- same memory, different interpretation */
    printf("%f\n", data.f);     /* 3.14 */
    printf("%d\n", data.i);     /* garbage now -- i and f share the same bytes */
    return 0;
}

19 Typedef

Gives an existing type a new, usually shorter or clearer, name — especially useful for structs and complex declarations.

typedef.c
typedef struct {
    int x;
    int y;
} Point;                    /* now "Point" can be used directly -- no "struct" prefix needed */
 
typedef unsigned long ulong;   /* shorter alias for a verbose built-in type */
 
int main(void) {
    Point p = {5, 10};        /* instead of: struct Point p */
    ulong big = 4000000000;
    printf("(%d, %d)\n", p.x, p.y);
    return 0;
}

20 Preprocessor Directives

Instructions that run before compilation even begins — text substitution and conditional inclusion of code.

preprocessor.h
#ifndef MYHEADER_H          /* "include guard" -- prevents double inclusion */
#define MYHEADER_H
 
#define PI 3.14159          /* simple macro constant */
#define SQUARE(x) ((x) * (x))  /* macro function -- watch the parentheses */
 
#ifdef DEBUG                 /* only compiled if DEBUG is defined elsewhere */
    #define LOG(msg) printf("[DEBUG] %s\n", msg)
#else
    #define LOG(msg)            /* expands to nothing in release builds */
#endif
 
#endif
Include guards (#ifndef / #define / #endif) stop a header from being processed twice if it's included by multiple files in the same build — without them, you'd get "redefinition" errors.

21 File Handling

C treats files through a FILE* handle, opened in a specific mode that determines what operations are allowed.

file_io.c
#include <stdio.h>
 
int main(void) {
    FILE *file = fopen("notes.txt", "w");   /* "w" -- write, overwrites existing file */
    if (file == NULL) {
        printf("Could not open file.\n");
        return 1;
    }
    fprintf(file, "Line one\n");
    fclose(file);                              /* always close what you open */
 
    file = fopen("notes.txt", "r");            /* "r" -- read only */
    char buffer[100];
    while (fscanf(file, "%99s", buffer) == 1) {
        printf("Read: %s\n", buffer);
    }
    fclose(file);
    return 0;
}
ModeMeaning
"r"Read — file must already exist
"w"Write — creates a new file, or overwrites an existing one
"a"Append — writes are added to the end of the file
"r+"Read and write, file must exist

fread and fwrite work the same way but move raw bytes rather than formatted text — useful for binary files and structs.

22 Error Handling

C has no exceptions — most functions signal failure through a return value, and the global errno variable explains why.

error_handling.c
#include <stdio.h>
#include <errno.h>
#include <string.h>
 
int main(void) {
    FILE *file = fopen("does_not_exist.txt", "r");
 
    if (file == NULL) {
        perror("fopen failed");          /* prints your message + the system's reason */
        printf("errno was: %d (%s)\n", errno, strerror(errno));
        return 1;
    }
    fclose(file);
    return 0;
}
perror() is the fastest way to report a failed system call — it automatically appends a human-readable explanation based on the current errno value.

23 Common Questions

A few things almost everyone asks in their first weeks with C.

C has no garbage collector. Memory you allocate with malloc/calloc/realloc stays reserved until you explicitly free it — forgetting to do so is a memory leak, and in a long-running program it can exhaust available memory entirely.
An array name decays into a pointer to its first element in most expressions, which is why arr[i] and *(arr + i) behave identically. But an array itself owns its memory and knows its size at declaration; a pointer is just an address and can be reassigned to point anywhere.
You're almost always accessing memory you don't own — dereferencing a NULL or dangling pointer, writing past the end of an array, or using memory after it's been freed. Tools like Valgrind or AddressSanitizer are the standard way to track these down.
calloc zero-initializes the memory it allocates; malloc leaves it as garbage. Use calloc when you need a clean starting state (like a fresh array of counters), and malloc when you're about to overwrite every byte anyway and want to skip the extra work.
Linked lists and other pointer-based data structures, the Makefile build system, multi-file projects with header files, and a debugger like gdb. After that, look at how an OS manages processes and memory — C is the natural on-ramp to systems programming.
